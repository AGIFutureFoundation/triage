The live demo — no signup, no slides

Tap a real, messy sample item — or paste your own — and watch the swarm work it. None of the agents is allowed to decide. Drex answers five typed questions; deterministic rules turn the probabilities into one explainable action.

Drex answers — one System One call, five typed questions

The routing rules, in order: unsubscribe ≥ 0.70 → SUPPRESS · wants-a-human ≥ 0.70 → HUMAN HANDOFF · grant + urgency ≥ 2 → ACT TODAY · interest ≥ 0.60 → CONVERSATIONAL REPLY · otherwise → FILE / NO ACTION. Decisions are probabilities — a human can always override.

Agent-to-agent, 100% interactive

SwarmTriage is built for agents first. Any agent can POST an agent-net style packet to /v1/decide and get a signed decision back — probabilities, the rule that fired, and a hash-chained packet id. Run the demo above and your run lands in this feed.

Packet format, auth and the x402 known-agent pattern are documented in llms.txt and agent.json. Feed entries on this page are generated in your browser for the demo.

The model stack — each model does the job it's best at

🧠 Drex (Nace AI) — decides

Every decision. Send a state plus named typed questions (noul / choice / score), get a calibrated probability for every answer in one call — POST /v1/systemone at console.nace.ai. Server-side only; the browser never holds the key.

👁️ NDI (Nace AI) — sees

The document layer. NDI parses, classifies, extracts, splits and grounds PDFs, spreadsheets, scans and emails into text Drex can decide about. Sample items on this page are shown in the grounded-text shape NDI hands back. Using NDI earns the Drexathon bonus — it's in the pipeline, not bolted on.

✍️ Claude (Anthropic) — drafts slot

Once Drex routes an item to CONVERSATIONAL REPLY, Claude drafts the human-quality reply for a person to approve. Slot in the architecture; it activates with the Anthropic connector on the server side. This demo page does not call Claude and does not pretend to.

📚 Gemini (Google) — summarises slot

Long-document summarisation for NDI-grounded files that are too long for one decision state. Slot in the architecture; it activates when a Gemini key is provisioned server-side. Not faked on this page.
